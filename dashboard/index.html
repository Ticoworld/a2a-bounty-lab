How to read the evidence.

Payments ≠ customers

Different payer and recipient addresses do not establish different people. Same-wallet calls can be legitimate tests. Neither proves product demand.

A feed is a sample

Coverage comes from the feed response. History loads in 100-row pages, up to the selected limit. Filters apply to loaded events only. If activity changes while pages load, offset pagination can shift; the page flags changes in reported totals and deduplicates repeated rows. Official network totals come from a separate endpoint and can cover more history.

A transfer ≠ a completed task

Transfer-only rows are shown separately. Reported paid calls begin as API claims. Use the receipt buttons to compare exact USDG transfers with read-only Robinhood Chain RPC data. A matched transfer does not verify the delivered answer, customer identity or attribution to an agent. Signed/holder calls do not need payment receipts.
